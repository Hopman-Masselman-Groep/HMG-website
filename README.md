# HMG Website

Website voor de Scouting Hopman Masselman Groep uit Soest.

## Ontwikkel omgeving instellen

### Vereisten

- Node.js (LTS versie)

### Installatie

```bash
npm install
```

### Development server

Start een lokale ontwikkelserver:

```bash
npm start
```

### Productie build

Maak een productie build:

```bash
npm run build
```

## Project Structuur

```
src/
├── assets/      # Statische bestanden
├── data/        # Site data
├── includes/    # Herbruikbare componenten
├── layouts/     # Pagina layouts
├── pages/       # Content pagina's
└── styles/      # CSS bestanden
```
